# BrightByte Kids Lab — Class 1 Demo

A mobile-first static learning portal for Class 1 Computer + AI basics.

## Files
- `index.html` — page structure
- `style.css` — responsive design
- `script.js` — lessons, game, quiz, stars, badges and local progress

## GitHub Pages deployment
1. Create a new GitHub repository, e.g. `brightbyte-kids`.
2. Upload these three files to the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then Save.
7. GitHub will show the public Pages URL after deployment.

## Important
This first version is static. Student progress is saved only in that browser using `localStorage`. It is ideal for UI/content testing. For real student accounts, parent accounts, teacher dashboard, shared progress, attendance and certificates, add a backend/database in Phase 2.
